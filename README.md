# AI-ассистент для приготовления блюд

Текстовый прототип кулинарного ассистента. Он ищет рецепты в PostgreSQL с
расширением pgvector, предлагает подходящие варианты и сопровождает приготовление
по шагам. Для общения доступны CLI и веб-чат на Gradio.

## Возможности

- Поиск до пяти похожих рецептов по текстовому запросу: эмбеддинг запроса
  сравнивается с векторами рецептов в PostgreSQL.
- Генерация ответа по найденным рецептам и истории диалога локальной LLM через
  Ollama.
- Выбор одного из предложенных рецептов.
- Переход к следующему шагу и возврат к предыдущему. Команды вроде «дальше»,
  «следующий шаг», «назад» и «предыдущий шаг» распознаются напрямую.
- Диалог с историей в CLI или Gradio. В Gradio можно очистить чат и начать новую
  сессию.

## Как устроен проект

```text
src/
  main.py                    # CLI-интерфейс
  agent/
    graph.py                 # LangGraph-граф и память диалога
    nodes.py                 # маршрутизация, поиск, выбор и шаги рецепта
    recipe_agent.py          # координация поиска и генерации ответа
    state.py                 # состояние диалога
    prompts/                 # промпты ассистента и классификаторов
  rag/
    search.py                # векторный поиск рецептов
    generate.py              # формирование ответа через Ollama
    steps.py                 # загрузка шагов из базы
  embeddings/model.py        # загрузка Sentence-Transformers
  database/                  # схема и подключение к PostgreSQL
ui/
  app.py                     # Gradio-чат
scripts/
  load_data.py               # загрузка рецептов и связанных данных
  generate_embeddings.py     # создание эмбеддингов
  experiments/
    check_description.py     # исследование описаний датасета
docker-compose.yml           # PostgreSQL с pgvector
requirements.txt
```

### Обработка запроса

1. LangGraph сохраняет состояние диалога и определяет намерение пользователя.
   Явные команды перехода между шагами распознаются по ключевым словам; остальные
   намерения определяет LLM через Ollama.
2. При поиске запроса Sentence-Transformers строит эмбеддинг, PostgreSQL
   возвращает до пяти ближайших рецептов.
3. Ollama формирует ответ с контекстом рецептов и предыдущими сообщениями.
4. При выборе рецепта ассистент определяет вариант из предложенного списка.
   Команды перехода по шагам загружают инструкции выбранного рецепта из базы.

В базе данных используются таблицы `recipes`, `ingredients`,
`recipe_ingredients` и `steps`. Размерность столбца `recipes.embedding` задана
как 1024, поэтому выберите модель Sentence-Transformers, которая создаёт
эмбеддинги именно такой размерности.

## Требования

- Python 3.10 или новее
- Docker и Docker Compose
- Ollama и установленная в ней языковая модель
- Sentence-Transformers-модель с эмбеддингами размерности 1024

## Установка и настройка

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

В командной строке Windows окружение можно активировать так:

```bat
.venv\Scripts\activate
```

Создайте `.env` на основе `.env.example` и укажите параметры PostgreSQL,
Sentence-Transformers-модель и Ollama-модель:

```dotenv
POSTGRES_USER=user
POSTGRES_PASSWORD=your_password
POSTGRES_DB=name_db
POSTGRES_PORT=5432

EMBEDDING_MODEL=имя_модели_sentence_transformers
LLM=имя_модели_ollama
```

Имена моделей должны быть доступны установленным библиотекам и Ollama
соответственно. Для Ollama загрузите выбранную модель командой
`ollama pull <имя_модели>`.

## Подготовка базы данных

Запустите PostgreSQL, создайте таблицы и загрузите данные:

```powershell
docker compose up -d
python -m src.database.init_db
python -m scripts.load_data
python -m scripts.generate_embeddings
```

Скрипт загрузки импортирует первые 1000 записей датасета
[RuRecipes-93k](https://huggingface.co/datasets/epishchik/RuRecipes-93k),
включая ингредиенты и шаги. Скрипт эмбеддингов обрабатывает до 1000 рецептов без
вектора за один запуск.

## Запуск

Запустите CLI:

```powershell
python -m src.main
```

Для завершения CLI введите `выход`, `exit` или `quit`.

Чтобы запустить веб-интерфейс:

```powershell
python -m ui.app
```

Откройте локальный адрес, который Gradio напечатает в терминале. Интерфейс
показывает историю сообщений; кнопка «Очистить чат» очищает историю и создаёт
новый контекст диалога.

Оба интерфейса используют один граф агента. Для CLI используется постоянный
идентификатор потока `cli`, а для каждого чата Gradio — отдельный идентификатор.
Память графа хранится в процессе приложения и не является долговременным
хранилищем.

## Текущие ограничения

- Голосовой ввод и озвучивание не подключены к текущему графу агента.
- В промпте перечислены намерения таймера и вопросов о рецепте, но отдельные
  обработчики для них пока не реализованы.
- Поиск использует семантические векторы названия рецепта и ингредиентов;
  фильтры по времени приготовления или кухне не подключены.
- Для поиска и генерации требуются запущенная база с подготовленными данными и
  доступная Ollama с выбранной моделью.
