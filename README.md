# Голосовой помощник-повар

Этот проект — голосовой ассистент для управления процессом приготовления блюд. Он распознаёт речевые команды, следит за шагами рецепта, поддерживает таймеры и контекст диалога. Проект выполнен в учебных целях и может быть доработан в будущем.

## Функциональность

- Распознавание 10+ команд (старт, следующий шаг, таймер, замена ингредиентов и т.д.)
- Поддержка контекста диалога (состояния `IDLE`, `COOKING`)
- Генерация текстовых ответов с помощью LLM (Vikhr-Qwen-2.5-0.5b-Instruct) для «оживления» общения
- Автономный синтез речи (pyttsx3)
- Офлайн-распознавание речи через Vosk
- Таймер с голосовым уведомлением
- Автоматическое определение окончания речи по тишине

## Используемые технологии

- **Python 3.11+**
- **Vosk** — офлайн-распознавание речи
- **Pyttsx3** — синтез речи
- **Transformers + Vikhr-Qwen-2.5-0.5b-Instruct** — генерация текстов
- **Sounddevice** — захват и воспроизведение звука
- **JSON** — хранение рецептов
